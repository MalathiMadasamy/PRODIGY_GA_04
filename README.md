# PRODIGY_GA_04

## Image-to-Image Translation with cGAN

### Objective

To implement an image-to-image translation model using a conditional Generative Adversarial Network (cGAN).

### Description

This project demonstrates image-to-image translation by taking an input image and generating a transformed output image using deep learning techniques.

### Tools and Technologies

* Python
* Google Colab
* PyTorch
* Pillow
* Matplotlib

### Procedure

1. Upload an input image.
2. Load the pre-trained model.
3. Process the image using the image-to-image translation model.
4. Generate the translated output image.
5. Display and save the output.

### Input

An RGB image provided by the user.

### Output

A translated image generated by the model.

### Result

Successfully implemented image-to-image translation and generated the corresponding output image.
